# StudyHub

StudyHub is a student-focused notes sharing platform built using Node.js, Express.js, MongoDB, HTML, CSS, and JavaScript.

Users can create accounts, securely log in using JWT authentication, manage their profiles, and upload academic notes for sharing.

## Features

- User Signup & Login Authentication
- JWT Cookie Authentication
- Profile Management
- Update User Information
- Secure Password Hashing with bcrypt
- Logout Functionality
- Responsive Dashboard UI
- Notes Upload System (In Progress)

## Tech Stack

Frontend:
- HTML
- CSS
- JavaScript

Backend:
- Node.js
- Express.js

Database:
- MongoDB

Authentication:
- JWT
- bcrypt

## Installation

```bash
git clone <repository-url>

cd StudyHub

npm install

npm start
```

## Environment Variables

Create a `.env` file:

```env
MONGO_URI=your_mongodb_connection

JWT_SECRET=your_secret_key
```
